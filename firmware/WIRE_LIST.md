# Лист проводов — бланк для заполнения

Этот файл — рабочий бланк: распишите в нём провода старой приборки, и по нему
я заполню таблицу `firmware/main/vehicle_signals.h` (после чего блок начнёт
отдавать реальные значения вместо нулей).

**Что нужно по каждому проводу** (четыре графы):

1. **Контакт** — номер контакта в разъёме старой приборки (и буква разъёма,
   если их несколько: у вас в статьях это `D` / `E` / `F`).
2. **Сигнал** — что это (левый поворотник, ручник, температура ОЖ, …).
3. **Как работает электрически** — самый важный пункт:
   * «плюс 12 В, когда срабатывает» — можно вешать на вход напрямую;
   * «замыкается на массу» — нужен резистор 4.7 кОм между проводом и +12 В
     (см. `firmware/README.md`, раздел «Провода на массу»);
   * «сопротивление меняется» (датчик) — нужна подтяжка + калибровка;
   * «напряжение 0…5 В» — можно на аналоговый вход напрямую;
   * «частота импульсов» — указываем, сколько импульсов на км или на оборот,
     если известно (иначе замерим).
4. **Примечание** — что угодно полезное: полярность, скважность, «проверено
   на машине», «сигнал берётся с реле», «идёт через блок предохранителей».

Если чего-то не знаете — ставьте `?`, это нормально: такие провода просто
проверим на машине мультиметром или осциллографом.

Подсказки по распределению (не правила, а здравый смысл):

* **ACC** — обязательно один из `DIN_1…DIN_6` (только эти выводы будят ESP32
  из сна). Соответственно один из них занимаем под него.
* **Скорость, обороты, расход от ЭБУ** — только `DIN_1…DIN_15` (у входов
  через PCF8574 опрос 50 Гц, частоту так не померить).
* **Стоп-сигналы и поворотники** — лучше на `DIN_1…DIN_15`: это быстрые
  сигналы, задержка заметна водителю.
* Остальное (габариты, туманки, задний ход, ручник, ремень, масло, ABS,
  Check Engine, селектор P/R/N/D, LOCK/SL, газ) можно и на `DIN_16…DIN_23`.

|---|---|---|---|---|---|
| 2 | `AIN0` | | | | |

| 17 | `AIN2` | | | | |
| 18 | `AIN3` | датчик уровня газа (помечено «ЛИНИЯ 5В») | 0…5 В | | если газ оставляем |

Важно: если датчик — это **сопротивление на массу** (уровень топлива,
температура), входу нужна подтяжка на провод датчика, иначе измерять нечего.
Напишите, чем питается провод датчика на вашей машине: идёт ли на него
напряжение от старой панели (тогда можно взять её же питание) или провод
«сухой».

## 5. Вопросы, на которые нужен ответ (можно коротко)

1. Модель/год машины и код двигателя; панель сейчас оптитронная или аналоговая?
2. Сигнал тахометра — откуда берётся: с катушки зажигания, с коммутатора или
   с ЭБУ? Если с катушки — важно проверить уровень (там выбросы).
3. Скорость — от датчика на коробке или от ЭБУ? Импульсов на километр,
   если известно.
4. Питание самой приборки (RK3588): от ACC или постоянно?
5. Расширять ли протокол до 1.3 ради координат GPS (см. `firmware/README.md`,
   раздел «GPS и навигация»)?
