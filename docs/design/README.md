# Референсы дизайна

Скриншоты, которые присылает заказчик по ходу обсуждения внешнего вида.
Это именно превью для обсуждения, а не исходники для сборки: для реализации
нужны макет в 1920×720 и активы (SVG/PNG) от дизайнера.

| Файл | Что это |
|---|---|
| `genesis.jpg` | Эскиз нового скина (800×600, JPG): тёмный сине-чёрный фон, два круглых прибора слева/справа, центральная колонка с данными, широкая светлая полоса внизу. Использовать как ориентир по настроению/палитре, не как источник размеров. |
| `climate.png` | Референс климатического виджета (см. задачу по климату, режим 6 центральной панели). |

План реализации по новому скину: заменить арт в `Dashboard/Gauge.qml`
(циферблат, стрелка, иконки), шлейф сделать по `docs/needle_trail.md`,
центр — по макету; подробности обсуждаются в переписке.
