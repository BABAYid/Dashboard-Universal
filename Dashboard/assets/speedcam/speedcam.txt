# Формат iGO / OpenSpeedcam (speedcam.txt):
#   X(долгота),Y(широта),TYPE,SPEED[,DIRTYPE,DIRECTION]
#   X и Y — градусы, дробная часть через точку (55.7520, 37.6175).
#   TYPE  — тип объекта (1 — камера контроля скорости, 2 — красный свет, ...).
#   SPEED — ограничение скорости в км/ч (0 — не задано).
#   DIRTYPE 0 — ненаправленная камера, 1 — направленная (в DIRECTION, 0..359).
# Строки, начинающиеся с '#', и пустые строки игнорируются.
#
# ЭТОТ ФАЙЛ — ЗАГЛУШКА. Он заменяется скриптом update_speedcam.sh (раз в сутки,
# systemd timer), а приборка читает его при старте. Пока в базе нет ни одной
# строки с координатами, предупреждения о камерах просто не появляются.
