============================================================
         CAN-ПРОТОКОЛ ПРИБОРНОЙ ПАНЕЛИ (версия 1.0)
============================================================
Автор: Проект "Audi Dashboard"
Дата: 2026-07-29
Скорость CAN: 500 кбит/с
Формат: 11-битный ID, 8 байт данных

------------------------------------------------------------
ID: 0x100 — СКОРОСТЬ И ОБОРОТЫ
------------------------------------------------------------
Назначение: передача текущей скорости и оборотов двигателя

Байт 0: Скорость (0–220 км/ч), uint8
Байт 1: Обороты (старший байт), uint8
Байт 2: Обороты (младший байт), uint8
Байт 3: Резерв (0)
Байт 4: Резерв (0)
Байт 5: Резерв (0)
Байт 6: Резерв (0)
Байт 7: Резерв (0)

Пример: скорость 102 км/ч, обороты 2450 об/мин
        0x66 0x09 0x92 0x00 0x00 0x00 0x00 0x00

------------------------------------------------------------
ID: 0x200 — ИНДИКАТОРЫ И ЛАМПЫ (битовая маска)
------------------------------------------------------------
Назначение: состояние ламп, индикаторов и предупреждений

Байт 0 — Свет и сигналы:
  Бит 0: Левый поворотник
  Бит 1: Правый поворотник
  Бит 2: Дальний свет
  Бит 3: Ближний свет
  Бит 4: Габариты
  Бит 5: Противотуманки
  Бит 6: Задний ход
  Бит 7: Стоп-сигналы

Байт 1 — Индикаторы состояния:
  Бит 0: Check Engine
  Бит 1: ABS
  Бит 2: Ручник
  Бит 3: Ремень безопасности (1 = непристёгнут)
  Бит 4: Давление масла (1 = авария)
  Бит 5: LOCK (SL) — блокировка АКПП
  Бит 6: Резерв
  Бит 7: Резерв

Байт 2: Резерв (0)
Байт 3: Резерв (0)
Байт 4: Резерв (0)
Байт 5: Резерв (0)
Байт 6: Резерв (0)
Байт 7: Резерв (0)

Пример: включены правый поворотник, ближний свет, ABS
        0x0A 0x02 0x00 0x00 0x00 0x00 0x00 0x00

------------------------------------------------------------
ID: 0x300 — ДАННЫЕ С ДАТЧИКОВ
------------------------------------------------------------
Назначение: передача аналоговых и цифровых показаний датчиков

Байт 0: Температура двигателя (0–120 °C), uint8
Байт 1: Уровень топлива (0–100 %), uint8
Байт 2: Напряжение бортсети (значение × 10, напр. 14.2 → 142), uint8
Байт 3: Наружная температура (-40…+60 °C, со знаком), int8
Байт 4: Давление масла (0 = норма, 1 = авария), uint8
Байт 5: Мгновенный расход топлива (0–99.9 л/100км, значение × 10), uint8
Байт 6: Резерв (0)
Байт 7: Резерв (0)

Пример: t_двиг=90°C, топливо=42%, напряжение=14.2В, -5°C, расход=8.5л/100км
        0x5A 0x2A 0x8E 0xFB 0x00 0x55 0x00 0x00

------------------------------------------------------------
ID: 0x400 — АКПП (режим, передача, LOCK, провода S1/S2/SL)
------------------------------------------------------------
Назначение: передача состояния автоматической коробки передач

Байт 0: Режим АКПП
  0 = P (Park)
  1 = R (Reverse)
  2 = N (Neutral)
  3 = D (Drive)
  4 = L (Low)

Байт 1: Номер передачи (только в режиме D)
  0 = не активно (не D-режим)
  1 = D1
  2 = D2
  3 = D3
  4 = D4

Байт 2: LOCK (SL) — 0 = выкл, 1 = вкл

Байт 3: Состояние провода S1 (0 = OFF, 1 = ON)
Байт 4: Состояние провода S2 (0 = OFF, 1 = ON)
Байт 5: Состояние провода SL (0 = OFF, 1 = ON) — дубль байта 2

Байт 6: Резерв (0)
Байт 7: Резерв (0)

Соответствие S1/S2 передачам:
  S1=ON,  S2=OFF → D1
  S1=ON,  S2=ON  → D2
  S1=OFF, S2=ON  → D3
  S1=OFF, S2=OFF → D4

Пример: режим D, передача D2, LOCK выключен, S1=ON, S2=ON, SL=OFF
        0x03 0x02 0x00 0x01 0x01 0x00 0x00 0x00

------------------------------------------------------------
ПРИМЕЧАНИЯ
------------------------------------------------------------
- Все CAN-пакеты имеют длину 8 байт (DLC = 8).
- Неиспользуемые байты заполняются нулями.
- При изменении протокола увеличивайте номер версии.
- Для K-Line (расход топлива) данные передаются через ID 0x300 (байт 5).
- Другие параметры K-Line могут быть добавлены в будущем через новые ID или резервные байты.
